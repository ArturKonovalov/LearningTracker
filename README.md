# 🥳 Трекер обучения — GORA Academy

Локальное приложение для отслеживания прогресса по курсу «ИИ-автоматизация».
Работает офлайн, в любом браузере, без установки и интернета.
Создано с помощью opencode на модели DeepSeek v4 Flash

## 🚀 Как запустить

1. Открой файл `trening-tracker.html` двойным кликом мыши (откроется в браузере).
2. Ничего настраивать не нужно.

### Обновление при смене версии
Если я пришлю новую версию файла — просто замени `trening-tracker.html` на новый.
Важно: **не удаляй** файл приложения и не открывай в новой вкладке «инкогнито»
(там прогресс не сохраняется). Твои данные хранятся в браузере, но привязаны к странице.

## ✨ Что умеет приложение

**📊 Дашборды**
- Прогресс основного обучения — в % и количестве (пройдено / осталось), зелёный бар.
- Прогресс дополнительных (бонусных) модулей — отдельный серый бар.
- График опережения/отставания от плана на 3,5 месяца: «Вы опережаете график на X% или Y дней».

**📚 Модули и уроки**
- Полный список модулей и уроков, отметка «пройден» (урок закрашивается зелёным).
- Две доп. галочки на урок: «ДЗ сдано» и «ДЗ принято».
- Нумерация уроков, сворачивание модулей, кнопки «Развернуть/Свернуть все».
- Добавление и удаление модулей и уроков — всё пересчитывается автоматически.

**🎉 Мотивация и геймификация**
- Салют из конфетти при прохождении урока.
- Модалка с цитатой и «приободряющими словами» (салют идёт, пока не закроешь).
- Увеличенный салют и поздравление при полном прохождении модуля и всего обучения.
- Календарь активности по месяцам (старт 02.11.2026).
- Фокус-таймер (помидорка): фокус + отдых, своя цель на день, салют при достижении цели,
  уведомления на компьютер/в браузер.

## 💾 Как сохраняется прогресс

- Всё сохраняется **автоматически** в браузере при каждом действии.
- Работает после закрытия вкладки — при новом открытии прогресс на месте.
- **Совет:** закрепи вкладку в браузере, чтобы не потерять.

## 🛠 Технические детали (для тех, кто хочет разобраться)

- **Один файл** → весь интерфейс, стили и логика (`HTML + CSS + JS`).
- Данные лежат в `localStorage` браузера (ключ `ak_learning_tracker_v1`, помидорки — `ak_pomo_v1`).
- Цитаты и фразы — прямо в коде (массив `QUOTES`, `CHEER_WORDS`, `MODULE_DONE_FRASES`).
- Чтобы изменить старт курса или длительность: в коде переменные `START` и `TOTAL_DAYS`.
- Это статический HTML — можно открыть напрямую с диска или закинуть на любой хостинг.
